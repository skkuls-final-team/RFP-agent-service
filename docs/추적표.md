# 추적표

> 자동 생성 파일이다. 손으로 고치지 않는다. `cd frontend && npm run trace`로 다시 만들고, CI(`npm run check:trace`)가 낡았는지 검사한다 (change `add-spec-trace`).
> 연결 설정은 `docs/추적_연결.json`. 시나리오·수용 기준과 테스트는 **이름이 같으면** 잇는다: 백엔드 테스트 docstring `Scenario: 이름`, e2e `test('이름')`와 바로 위 `// Scenario: 이름`, 도구 테스트 `test('Scenario: 이름')`, 화면 명세 수용 기준 줄 끝 `(이름)`.

- 명세서 FR 17개, OpenSpec capability 24개
- OpenSpec 시나리오 724개 중 테스트가 있는 것 **720개 (99 %)**
- 화면 명세 수용 기준 161개 중 e2e가 있는 것 **155개 (96 %)**
- 테스트: 백엔드 76개 파일, e2e 55개 파일, 도구 1개 파일
