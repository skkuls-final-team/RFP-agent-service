## ADDED Requirements

### Requirement: 시연 준비 명령
시스템은 검토가 없는 DB에 마이그레이션·규칙 사전·실제 제품표·합성 RFP 28 정답지(요구사항·유형)와 사업 하나의 파일 28 검토 1건(담당자 확인 단계까지)을 한 명령으로 준비해야 한다(SHALL). 검토가 하나라도 있는 DB에서는 아무것도 바꾸지 않고 거절해야 하며(MUST NOT 지우기), 시연 파일이 없으면 시작 전에 멈추고 만드는 법을 알려야 한다(SHALL). AI는 지금 설정을 따르고 방식을 알린다. [제안 11-03]

#### Scenario: 빈 DB에 시연 준비
- **WHEN** 검토가 없는 DB에서 시연 준비 명령을 돌리면
- **THEN** 정답지 2개(Claude 초안), 사업 "시연 사업"과 그 사업의 검토 1건이 담당자 확인 단계로 생긴다

#### Scenario: 검토가 있는 DB
- **WHEN** 검토가 1건 있는 DB에서 시연 준비 명령을 돌리면
- **THEN** 거절하고 정답지·사업·검토 수가 그대로다

#### Scenario: 시연 파일 없음
- **WHEN** 시연 파일이 없는 상태로 시연 준비 명령을 돌리면
- **THEN** 아무것도 바꾸기 전에 멈추고 파일 만드는 명령을 알린다
