# 시연 준비 명령

## 왜

- 개발 DB에는 시험·e2e로 만든 검토가 300건 넘게 쌓여 있다. 정답지·채점 화면이 사람 확인 판정이 있는 검토를 미리 골라 두어(스펙대로) 시연에서 검토 327건이 한꺼번에 채점됐다(2026-11-02).
- 시연용 DB를 준비하려면 마이그레이션·사전·실제 제품표·합성 RFP 정답지 넣기·파일 28 검토 등록을 사람이 차례로 해야 하고, 빠뜨리기 쉽다.

## 무엇

- `rfp-db demo-setup [--create] [--file 파일]`: `DATABASE_URL`이 가리키는 DB에 시연 데이터를 한 번에 준비한다.
  - `--create`: 같은 서버에 그 이름의 DB가 없으면 만든다.
  - 마이그레이션 → 규칙 사전 → 실제 제품표 → 합성 RFP 28 정답지 2개(요구사항·유형, Claude 초안) → 사업 "시연 사업"에 파일 28 검토 1건(제출 마감 14일 뒤, 담당 기본 엔지니어)을 분석해 담당자 확인 단계까지.
  - AI는 지금 설정(`RFP_AI_MODE`)을 따르고, 시작할 때 방식을 한 줄로 알린다.
- 안전: 검토가 하나라도 있는 DB는 아무것도 바꾸지 않고 거절한다. 지우는 일은 하지 않는다. 파일 28이 없으면 시작 전에 만드는 법을 알리고 멈춘다.

## 하지 않음

- 기존 DB 비우기·덮어쓰기.
- 화면.
