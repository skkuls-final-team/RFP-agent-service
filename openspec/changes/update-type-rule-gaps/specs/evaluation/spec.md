## MODIFIED Requirements

### Requirement: 시연용 합성 RFP 정답지
시스템은 시연용 합성 RFP 파일 28의 요구사항 정답지(요구사항 65줄, 위험 조건 4줄, 값이 있는 줄은 값·단위)와 유형 정답지(65줄)를 저장소의 기준 데이터로 가져야 하며, 둘 다 만든 이는 Claude 초안(사람 확인 전)이어야 한다(SHALL). 정답은 시스템 결과가 아니라 문서를 읽고 고른 것이다. 파일 28을 처리한 검토를 이 정답지로 채점할 수 있어야 한다(SHALL). [제안 11-02]

#### Scenario: 합성 RFP 정답지 넣기
- **WHEN** 파일 28 요구사항 정답지와 유형 정답지를 넣으면
- **THEN** 요구사항 정답지 69줄(대상 문서 파일 28), 유형 정답지 65줄이 빠진 줄 없이 들어가고 만든 이는 Claude 초안이다

#### Scenario: 합성 RFP 정답지 채점
- **WHEN** 파일 28을 AI 없이 처리한 검토를 두 정답지로 채점하면
- **THEN** K1 65/65, K2 65/67, K3 30/30, K10 4/4, K13 42/42이다 (유형 규칙 보강 뒤, update-type-rule-gaps)
