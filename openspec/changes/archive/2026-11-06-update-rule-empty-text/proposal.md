# Proposal

## Why

판정 규칙 화면(SCR-17) 항목 이름 탭의 "항목 이름 · 연결 후보" 상자에 후보가 없으면 "연결 후보가 없습니다. AI를 사용한 분석에서만 만들어집니다."가 낱말마다 줄이 바뀌어 세로로 길게 보인다. 안내 줄이 후보 줄과 같은 네 칸 격자를 써서 첫 칸(54px)에 들어가기 때문이다. 위 "사람이 제안한 표현" 상자의 빈 안내도 같은 구조다. 팀 확인 사항으로 올라왔다(11-06).

관련: SCR-17 판정 규칙, add-meaning-search, add-rule-suggestion.

## What Changes

- 두 상자의 빈 안내 줄은 칸으로 나누지 않고 상자 너비 전체에 한 줄로 보인다.

## Non-Goals

- 후보·제안 줄의 칸 배치와 문장은 그대로.
