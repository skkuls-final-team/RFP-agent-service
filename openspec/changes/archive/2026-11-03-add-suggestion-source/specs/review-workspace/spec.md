## MODIFIED Requirements

### Requirement: 사전 추가 제안 화면
화면은 위험 조건 탭 "사람이 찾은 특이 요구"에서 놓친 표현과 메모를 넣어 제안하고 이 검토의 제안(표현, 찾은 곳, 상태)을 보여야 하며, 판정 규칙 화면 "사람이 제안한 표현"에서 제안을 확인 대기부터 보이고 엔지니어·승인자에게 [반영]·[반려]를 보여야 한다(SHALL). 판정 규칙 화면 목록은 칸 이름 줄(제안일 · 제안한 표현 · 제안한 곳 · 상태 · 처리)을 두고 모든 줄을 같은 칸 폭으로 그려, 확인 대기 줄의 [반영]·[반려]와 끝난 제안의 처리 날짜·사람이 같은 처리 칸에 놓인다. 판정 규칙 화면에서 제안 줄을 누르면 줄 아래에 그 표현이 나온 원래 문장 전체(표현 강조)와 원문 위치 모두, 메모·반려 사유를 펼치고 다시 누르면 접는다. [반영]·[반려]·링크를 눌러서는 펼치지 않는다. [반영]은 표현을 채운 규칙 추가 창을 연다. 예시 띠를 붙이지 않는다. [제안]

#### Scenario: 제안하고 반영하기
- **WHEN** 엔지니어가 위험 조건 탭에서 문서에 있는 표현을 제안하고, 판정 규칙 화면에서 그 제안을 반영하면
- **THEN** 위험 조건 탭에 "확인 대기"로 보였던 제안이 판정 규칙 화면에서 "반영"으로 바뀌고 위험 표현 탭에 그 표현이 보인다

#### Scenario: 제안 목록 칸 맞춤
- **WHEN** 확인 대기 제안과 반영된 제안이 함께 있는 판정 규칙 화면을 열면
- **THEN** 목록 위에 "제안한 표현"·"제안한 곳"·"상태"·"처리" 칸 이름이 보이고, 두 줄의 상태 칸이 같은 가로 위치에서 시작한다

#### Scenario: 제안 줄 펼쳐 원문 보기
- **WHEN** 엔지니어가 판정 규칙 화면에서 문장 일부만 제안된 줄을 누르면
- **THEN** 줄 아래에 원래 문장 전체가 보이고 제안한 표현이 강조되며 원문 위치가 보이고, 다시 누르면 접힌다
