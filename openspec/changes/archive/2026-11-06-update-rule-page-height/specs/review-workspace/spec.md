## ADDED Requirements

### Requirement: 판정 규칙 표 쪽 높이 유지
판정 규칙 화면의 비교 방향·위험 표현·항목 이름·문서 종류 탭은 규칙이 여러 쪽일 때 줄이 적은 쪽에서도 꽉 찬 쪽의 표 높이를 유지해, 쪽 번호 줄이 위로 올라오지 않게 해야 한다(SHALL). 탭·검색어·쪽 크기가 바뀌면 높이를 다시 정해야 한다(SHALL). [제안 11-06]

#### Scenario: 마지막 쪽도 표 높이 유지
- **WHEN** 규칙이 12건인 탭에서 10건씩 1쪽을 본 뒤 2쪽(2건)을 누르면
- **THEN** 표 영역 높이와 쪽 번호 줄 위치가 1쪽과 같고, 다른 탭으로 바꾸면 그 탭 줄 수에 맞춰 다시 정해진다
