# Proposal

## Why

판정 규칙 화면(SCR-17)의 비교 방향·위험 표현·항목 이름·문서 종류 탭에서 1쪽에 10건을 보다가 마지막 쪽(예: 2건)을 누르면 표가 2건 높이로 줄어든다. 아래 쪽 번호 줄과 그 아래 내용이 위로 올라와, 쪽을 넘길 때마다 화면이 튀고 누르던 쪽 번호가 손 밑에서 사라진다. 팀 확인 사항으로 올라왔다(11-06).

관련: SCR-17 판정 규칙, add-reference-views, add-rule-editing.

## What Changes

- 판정 규칙 네 탭에서 쪽이 둘 이상일 때, 줄이 적은 쪽도 꽉 찬 쪽(쪽 크기만큼 줄)을 그린 표 높이를 유지한다. 남는 자리는 비워 둔다.
- 탭·검색어·쪽 크기를 바꾸면 높이를 다시 정한다.

## Non-Goals

- 검토 상세 탭(위험 조건·문서 읽기 점검 등)과 다른 화면의 쪽 나누기는 바꾸지 않는다.
- 쪽 크기·쪽 번호 모양은 그대로.
