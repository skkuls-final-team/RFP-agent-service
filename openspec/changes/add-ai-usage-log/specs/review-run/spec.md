## ADDED Requirements

### Requirement: 분석 밖 AI 사용량 기록
시스템은 분석 실행 밖에서 AI를 부른 요청(검토 도우미 질문, 협조 요청 확인할 점, 비교 제품 바꾸기·손실값 고치기·판정 확정 뒤 다시 만들기)마다 기능·검토·모델·호출 수·재시도·토큰을 남겨야 하고, AI를 부르지 않은 요청은 남기지 않아야 한다(SHALL). 날짜·기능별 사용량과 추정 비용(팀 가정 단가)을 분석 실행 사용량과 함께 돌려줘야 한다(SHALL). [제안 11-03]

#### Scenario: 검토 도우미 사용량
- **WHEN** AI가 켜진 상태에서 검토 도우미에 질문하면
- **THEN** 사용량에 검토 도우미 한 줄(그 검토, 호출 수, 토큰)이 남는다

#### Scenario: AI를 부르지 않은 요청
- **WHEN** AI가 꺼진 상태에서 검토 도우미에 질문하면
- **THEN** 사용량은 남지 않는다

#### Scenario: 날짜·기능별 사용량
- **WHEN** 같은 날 검토 도우미 질문 2번과 AI를 쓴 분석 1건이 있으면
- **THEN** 사용량 응답에 그날 검토 도우미(호출 합)와 분석 줄이 따로 있고, 합계에 추정 비용이 있다
