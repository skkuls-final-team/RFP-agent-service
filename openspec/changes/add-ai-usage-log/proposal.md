# 분석 밖 AI 사용량 기록

## 왜

- 실행 기록(add-run-log)은 분석 한 건의 AI 호출 수·토큰·추정 비용만 남긴다. 분석 밖에서 AI를 부르는 곳(검토 도우미 질문, 협조 요청 메일의 확인할 점, 비교 제품 바꾸기·손실값 고치기·판정 확정 뒤 초안 다시 만들기)은 어디에도 남지 않는다.
- 2026-11-02 docker 백엔드가 Gemini 모드로 떠 있어 검토 도우미 질문 16번이 Gemini로 갔는데, 사용량을 몰라 서버 로그로 횟수만 세고 비용은 어림했다. AI 비용을 확인할 수 없다(NFR, CR-12 운영).

## 무엇

- 분석 밖 요청마다 AI를 실제로 불렀으면(호출 1회 이상) 기능·검토 번호·모델·호출 수·재시도·입력/출력/생각 토큰·시각을 남긴다(새 표 `ai_usage`).
- `GET /api/ai-usage?days=30`: 날짜·기능별 호출 수·토큰·추정 비용(실행 기록과 같은 팀 가정 단가)과 합계. 분석 실행의 사용량(review_run)도 "분석" 기능으로 함께 합쳐 한 곳에서 본다.
- AI를 부르지 않은 요청(AI 끔, 규칙만)은 남기지 않는다.

## 하지 않음

- 화면. 응답만 만들고 화면(실행 기록 화면 등)은 따로 한다(화면 작업 몫).
- 실제 청구 금액 대조(Google 결제는 밖에서 확인).

관련: add-run-log(NFR-09), add-ai-mode, 2026-11-02 비용 확인 대화.
